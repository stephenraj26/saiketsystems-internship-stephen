# Task 2: Responsive Web Page (E-commerce Landing Page)

Landing page for "Kaapi Corner", a demo online filter coffee store.

## Built with
- HTML5, CSS3, Bootstrap 5
- Vanilla JavaScript

## Features
- Responsive on mobile, tablet and desktop
- Hero, features, product grid, newsletter form and footer
- JavaScript: cart counter, dark mode toggle, email validation

## Run it
Open `index.html` in any browser.
