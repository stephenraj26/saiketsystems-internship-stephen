# Saiket Systems Internship - Task 1: Static Portfolio Website

A responsive portfolio website with a homepage, a Projects section (placeholders)
and a contact form with JavaScript validation.

## Built with
- HTML5, CSS3
- Bootstrap 5
- Vanilla JavaScript

## Run it
Open `index.html` in any browser.

## Features
- Responsive on mobile, tablet and desktop
- Theme: cream, forest green and coral
- Contact form checks name, email, subject and message, with a live character counter
